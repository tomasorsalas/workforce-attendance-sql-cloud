# Consultas de asistencia

[queries.sql](queries.sql) ofrece las ocho consultas de análisis sobre el esquema de este proyecto. Su contenido SQL coincide con [sql/04_queries.sql](../sql/04_queries.sql); ejecutar uno de los dos archivos después de cargar las tablas, los datos y la vista.

El estado de marcaje y las alertas de horario se calculan por separado. El tiempo adicional observado indica una salida posterior al horario programado; su autorización requiere información ajena al modelo.

La [instalación](../README.md) describe el orden de carga y las [pruebas](../docs/validacion.md) detallan los resultados esperados del dataset sintético.
